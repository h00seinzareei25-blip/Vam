# Vam — مدیریت بدهی‌ها

اپ اندروید مدیریت بدهی‌ها و ریز اقساط با یادآوری نوتیفیکیشن.

## نصب

فایل APK از مسیر زیر در ریپازیتوری/آرتیفکت‌ها قابل دانلود است:

- `android-app/` — سورس کامل اپ اندروید
- خروجی بیلد: `app/build/outputs/apk/`

## قابلیت‌ها

- ثبت و ویرایش بدهی/وام و اقساط
- آمار ماه جاری و نزدیک‌ترین سررسید
- خروجی و بازیابی JSON
- یادآوری نوتیفیکیشن (روز سررسید + ۱ و ۳ روز قبل، ساعت ۹ صبح)
